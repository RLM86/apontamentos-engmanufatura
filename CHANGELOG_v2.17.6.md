# Aponta P3 v2.17.6 — Devolução após aprovação

- Nova área administrativa na tela Fechamento.
- Disponível apenas para perfil Administrador.
- Funciona somente quando o fechamento selecionado está Aprovado.
- Motivo da devolução obrigatório.
- Opção Devolver ao colaborador:
  - fechamento passa para Devolvido;
  - apontamentos aprovados passam para Devolvido;
  - colaborador pode editar, excluir e enviar novamente.
- Opção Voltar para aprovação do gestor:
  - fechamento passa para Enviado;
  - apontamentos aprovados passam para Enviado;
  - colaborador continua sem poder editar;
  - gestores podem revisar novamente.
- Operação realizada por RPC administrativa e transação única.
