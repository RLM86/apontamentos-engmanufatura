# Aponta P3 v2.16.0

- Permite várias salas do mesmo tipo em um projeto.
- Cada sala física recebe número e nome próprios.
- Cada sala possui sua própria quantidade de módulos.
- Cada módulo possui parte inferior e parte superior.
- Apontamento estrutural passa a selecionar Sala específica > Módulo > Parte.
- Cadastros e edição administrativa atualizados.
- Migração preserva a estrutura e os apontamentos antigos.
