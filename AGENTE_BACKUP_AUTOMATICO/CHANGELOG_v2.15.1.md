# Aponta P3 v2.15.1 — Quantidade de módulos livre

- Removido o limite fixo de oito módulos por sala.
- Cada projeto pode possuir uma quantidade diferente de módulos em cada sala.
- Campo numérico editável diretamente na composição do projeto.
- Botões de diminuir e aumentar quantidade.
- Quantidade existente é carregada automaticamente ao selecionar o projeto.
- A quantidade pode ser aumentada ou reduzida a qualquer momento.
- Ao reduzir, os módulos excedentes são inativados para preservar o histórico.
- MONOBLOCO permanece fixo em uma unidade.
- Não exige novo SQL.
