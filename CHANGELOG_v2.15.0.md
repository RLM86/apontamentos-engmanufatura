# Aponta P3 v2.15.0 — Composição do projeto

- Tela Estrutura por projeto substituída por uma configuração visual de composição.
- Premissa aplicada: projeto com DH, SE, SC, SM e HVAC, ou somente MONOBLOCO.
- Cada sala aceita de 1 a 8 módulos; MONOBLOCO fica limitado a 1 unidade.
- Resumo e módulos avançados filtrados pelo projeto selecionado.
- Subaba exclusiva para Feriados.
- Botão Excluir adicionado a setores, tipos de painel, salas, salas do projeto e módulos por sala.
- Cadastros compactados e responsivos.
- Não exige novo SQL; utiliza a estrutura do banco v2.13.
